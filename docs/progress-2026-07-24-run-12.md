# KidsMonnter — Run 12

## ما تمت مراجعته

- `lib/main.dart` وحالة Device Owner المعروضة للمستخدم.
- `native/MainActivityV2.kt` وسياسات `DevicePolicyManager`.
- خدمة الخلفية واحتساب الوقت عبر `SystemClock.elapsedRealtime()`.
- استعادة الخدمة بعد إزالة التطبيق من المهام وإعادة تشغيل الجهاز.
- `native/AndroidManifest.xml` واختبار عقد Android الأساسي.
- مسار GitHub Actions المسؤول عن التحليل والاختبارات وبناء APK.

## المشكلة

كانت الواجهة تعتبر وجود التطبيق كـ Device Owner وحده دليلًا على أن منع الحذف مطبق. هذا غير دقيق؛ فقد يكون التطبيق Device Owner بينما تفشل سياسة `setUninstallBlocked` على جهاز أو نظام معين.

## التغيير

- إضافة ترقية idempotent تربط Android Native بـ `DevicePolicyManager.isUninstallBlocked`.
- إضافة الحقل `uninstallBlocked` إلى حالة سياسات الجهاز في `main.dart`.
- اعتبار منع الحذف فعالًا فقط عند تحقق Device Owner وDevice Admin ونتيجة منع الحذف الفعلية.
- جعل مسار البناء يرفض المتابعة إذا لم تُدمج الحقول الجديدة في المصدرين.
- تشغيل التنسيق والتحليل والاختبارات وبناء APK بعد الدمج.
- حفظ `main.dart` و`MainActivityV2.kt` المدمجين مع APK على الفرع الرئيسي عند نجاح البناء.

## ما لم يتغير

- منطق PIN.
- احتساب الوقت أثناء تشغيل الشاشة.
- شاشة القفل.
- إضافة الوقت وفتح الهاتف لبقية اليوم.
- تخزين البريد والمحاولات الفاشلة.

## ما بقي

بعد نجاح البناء، يلزم اختبار هاتف حقيقي لحالات: الخروج من التطبيق، إزالة التطبيق من المهام، إعادة تشغيل الهاتف، انتهاء الوقت، Overlay، وDevice Owner/منع الحذف.
