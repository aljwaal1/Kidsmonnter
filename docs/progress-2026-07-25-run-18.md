# تقدم KidsMonnter — التشغيل 18

## ما تمت مراجعته

- آخر بناء ناجح بعد إضافة طلب إذن الإشعارات.
- خدمة `MonitorService` وإشعار Foreground المستمر.
- مسار فتح الواجهة الرئيسية `MainActivity`.
- اختبارات العقود ومسار GitHub Actions قبل بناء APK.

## المشكلة

إشعار خدمة الحماية كان مستمرًا لكنه لا يحتوي على `contentIntent`. لذلك الضغط على الإشعار لا يفتح لوحة ولي الأمر، ويضطر المستخدم إلى البحث عن التطبيق يدويًا عند الحاجة إلى فحص الخدمة أو الوقت أو معالجة مشكلة في الحماية.

## التغيير المنفذ

- إضافة `guardNotificationContentIntent()` باستخدام `PendingIntent.getActivity`.
- فتح `MainActivity` مع `FLAG_ACTIVITY_CLEAR_TOP` و`FLAG_ACTIVITY_SINGLE_TOP` لمنع إنشاء نسخ متكررة من الشاشة.
- استخدام `FLAG_IMMUTABLE` و`FLAG_UPDATE_CURRENT`.
- ربط الـPendingIntent بإشعار الحماية عبر `setContentIntent`.
- إضافة اختبار عقد وفحوص بناء تمنع فقدان الربط لاحقًا.

## ما لم يتغير

- احتساب وقت الاستخدام.
- شاشة القفل.
- PIN والتخزين.
- Watchdog واستعادة الخدمة.
- صلاحيات Overlay وDevice Owner.
- نصوص التحذيرات وتنبيهات انتهاء الوقت.

## ما بقي

- انتظار نجاح التحليل والاختبارات وبناء APK الجديد.
- اختبار الضغط على إشعار الحماية على هاتف فعلي والتأكد من فتح لوحة ولي الأمر دون إنشاء شاشة مكررة.
