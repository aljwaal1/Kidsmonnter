# تقدم KidsMonnter — التشغيل 06

## ما تمت مراجعته

- `lib/main.dart` ونموذج `GuardStatus` الحالي.
- `lib/guard_diagnostics.dart` وحالات صحة الخدمة والجاهزية.
- `lib/guard_diagnostics_presentation.dart` ورسائل العرض العربية.
- الاختبارات السابقة الخاصة بالتشخيص والعرض.
- مسار GitHub Actions الذي يشغّل التحليل والاختبارات قبل بناء APK.

## ما تم تغييره

- إضافة `lib/guard_diagnostics_card.dart` كبطاقة واجهة مستقلة وقابلة لإعادة الاستخدام.
- البطاقة تعرض حالة الخدمة وشاشة القفل دون تكرار منطق التشخيص داخل Widgets.
- إضافة زر معالجة اختياري فقط للحالات التي تتطلب تدخل المستخدم.
- إضافة `test/guard_diagnostics_card_test.dart` لتغطية:
  - خدمة سليمة وصلاحية Overlay موجودة.
  - خدمة سليمة مع نقص Overlay واستدعاء إجراء المعالجة.
  - نبضة قديمة وتصنيف الخدمة على أنها لا تستجيب.

## ما لم يتغير

- خدمة Android Native.
- احتساب وقت الاستخدام.
- شاشة القفل.
- Manifest والصلاحيات.
- تخزين PIN.
- نموذج البيانات الحالي داخل `main.dart`.

## ما بقي

1. تأكيد نجاح `flutter analyze` و`flutter test` وبناء APK بعد إضافة البطاقة.
2. إضافة `serviceHeartbeatMs` إلى `GuardStatus.fromMap`.
3. إدراج `GuardDiagnosticsCard` داخل الشاشة الرئيسية.
4. توجيه زر معالجة المشكلة إلى إعدادات Overlay عند نقص الصلاحية، أو إلى محاولة تحديث/إعادة تشغيل الخدمة عند قدم النبضة.
5. إضافة اختبار تكامل للربط بين خريطة Native ونموذج التشخيص والبطاقة.
