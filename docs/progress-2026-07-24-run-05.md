# تقدم KidsMonnter — التشغيل 05

## ما تمت مراجعته

- آخر commits الخاصة بتشخيص نبض خدمة الخلفية.
- `lib/main.dart` للتأكد من أن الواجهة الحالية لا تزال لا تعرض `serviceHeartbeatMs`.
- `lib/guard_diagnostics.dart` وحالات الجاهزية الخمس.
- مسار البناء السابق ووجود APK مبني بعد محرك Native V2.

## ما تم تغييره

أضيفت طبقة عرض مستقلة في:

- `lib/guard_diagnostics_presentation.dart`

وتحوّل حالات `GuardReadiness` إلى نصوص عربية واضحة ومستوى دلالة وحالة تتطلب تدخل المستخدم أو لا تتطلبه.

أضيفت اختبارات في:

- `test/guard_diagnostics_presentation_test.dart`

وتغطي حالات توقف الحماية، بدء الخدمة، الجاهزية، نقص Overlay، وتوقف نبض الخدمة، إضافة إلى تنسيق عمر آخر نبضة.

## سبب فصل طبقة العرض

- منع وضع منطق التشخيص داخل Widgets.
- جعل النصوص والحالات قابلة للاختبار دون تشغيل Android.
- تسهيل ربط بطاقة التشخيص بالواجهة في تغيير صغير لاحق.
- تقليل احتمال أن يؤثر تعديل واجهة المستخدم في منطق خدمة الحماية.

## ما بقي

1. إضافة `serviceHeartbeatMs` إلى `GuardStatus`.
2. إنشاء `GuardDiagnostics` من حالة Android الحالية.
3. عرض بطاقة التشخيص داخل `HomeScreen`.
4. إظهار زر تفعيل Overlay فقط عند الحالة المناسبة.
5. تأكيد نجاح `flutter analyze` و`flutter test` وبناء APK بعد الربط.

لم يتم تغيير Manifest أو خدمة Android أو القفل أو حساب الوقت في هذا التشغيل.
